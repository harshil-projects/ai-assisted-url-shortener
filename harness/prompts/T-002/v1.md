## Role and ground rules

You are generating Java 21 / Spring Boot 4.1.1 code for the URL shortener in this repository.
The engineer reviews every file you produce; your output is a draft, not a decision.

Read first, in this order: `docs/design/2026-10-12-system-design.md` sections 3.2 to 3.10 and 4.2,
4.3; then the existing skeleton under `url-shortener/src` (poms, properties, V1 migration,
`SecurityConfig`, `ApiKeyFilter`, `ProblemDetails`, `ProblemTypes`, `ProblemWriter`,
`AppProperties`, `TestProfile`, `SecuritySmokeIT`). Reuse them; do not duplicate them.

Hard constraints:

- Spring Boot 4 idioms only: `spring-boot-starter-webmvc`, `@MockitoBean` (never `@MockBean`),
  `tools.jackson.*` (never `com.fasterxml.*`), `@AutoConfigureMockMvc` or `MockMvcTester`,
  `@AutoConfigureRestTestClient` with `RestTestClient` for full-context tests, Spring Security 7
  lambda DSL. Jackson 3 fails a missing primitive with a generic 400, so DTOs use boxed types with
  `@NotNull`.
- Constructor injection only. Records for DTOs. Methods under 50 lines, files under 400 lines.
  Google Java Style (run `./mvnw.cmd -B -ntp spotless:apply` before every verify).
- No new Maven dependencies. No edits to `pom.xml`, `application*.properties`,
  `config/checkstyle/*`, `SecurityConfig`, `ApiKeyFilter`, `ProblemWriter`, `ProblemDetails`,
  `ProblemTypes`, `AppProperties`. If you believe one of these must change, write the proposed
  change in your final report instead of making it.
- Do not create these files, another session owns them: `config/RequestIdFilter`,
  `config/RateLimitFilter`, `config/RequestSizeFilter`, `config/FilterRegistrations`,
  `config/OpenApiConfig`, `api/OpenApiErrorCustomizer`, and any test named `ApiKeyIT`,
  `RateLimitIT`, `SecurityHeadersIT`, `ProblemDetailIT`, `ActuatorIT`, `OpenApiIT`,
  `ProdStartupIT`.
- Never log a full target URL; log the code and the host at most, through `LogSanitizer`.
- Never persist IP addresses or user agents (ADR 0006).
- Every test class carries `@TestProfile`. `@DataJpaTest` classes also carry
  `@AutoConfigureTestDatabase(replace = Replace.NONE)` so Flyway runs against the configured H2.
- Keep the total number of `POST /api/v1/links` calls per Spring context under 50; the test
  profile rate limit is 100 per minute. Loops belong in unit tests against the service.
- Every integration test cleans `click_events` and `links` in `@AfterEach`.
- Do not run git. Do not create files outside `url-shortener/src`.
- Finish with `./mvnw.cmd -B -ntp verify` green (format, style, SpotBugs with FindSecBugs, tests,
  JaCoCo 80 percent line, 70 percent branch, no untested class). Fix findings in code; add a
  SpotBugs exclusion only with a written reason in `config/spotbugs/exclude.xml` and mention it in

## Task T-002: schema entities and repositories

Files: `domain/Link.java`, `domain/ClickEvent.java`, `repository/LinkRepository.java`,
`repository/ClickEventRepository.java`, `repository/ClickSummary.java` (record projection),
tests `repository/MigrationTest.java`, `repository/ClickEventRepositoryTest.java`,
`repository/LinkRepositoryTest.java`.

- `Link`: `@Entity @Table(name = "links")`; `id` Long identity; `code` String(32) unique;
  `originalUrl` String(2048) column `original_url`; `createdAt` Instant column `created_at`.
  `equals`/`hashCode` on `code`; `toString` excludes `originalUrl`. Protected no-arg constructor for
  JPA plus a public constructor `(code, originalUrl, createdAt)`. No setters except what JPA
  needs; prefer none.
- `ClickEvent`: `@Entity @Table(name = "click_events")`; `id`, `linkId` Long column `link_id`
  (plain column, no relationship), `occurredAt` Instant column `occurred_at`.
- `LinkRepository extends JpaRepository<Link, Long>`: `Optional<Link> findByCode(String code)`,
  `boolean existsByCode(String code)`, `long deleteByCode(String code)`.
- `ClickEventRepository extends JpaRepository<ClickEvent, Long>` with one JPQL aggregate:
  total count, count where `occurredAt >= :since24h`, count where `occurredAt >= :since7d`,
  `max(occurredAt)`, for `linkId`, returned as `ClickSummary(long total, long last24h, long last7d,
  Instant lastClickedAt)` using `coalesce` so an empty link yields zeros and null.
- `MigrationTest`: `@DataJpaTest` asserts `uk_links_code`, `fk_click_events_link` and
  `ix_click_events_link_time` exist via `information_schema`, and `flyway_schema_history` has
  version 1 successful.
- `ClickEventRepositoryTest`: inserts events at controlled instants and asserts the summary
  windows and `lastClickedAt`; asserts cascade delete removes events when the link is deleted via
  JDBC.

## Task T-003: code generation and URL validation

Files: `service/CodeGenerator.java`, `service/UrlValidator.java`, `domain/ReservedWords.java`,
`domain/LogSanitizer.java`, `domain/UrlValidationException.java` (carries a list of
`FieldError(field, message)` records), tests `CodeGeneratorTest`, `UrlValidatorTest`
(parameterised, at least 30 URLs covering every rule below), `ReservedWordsTest`,
`LogSanitizerTest`.

- `CodeGenerator.next()` returns 7 characters from the Base62 alphabet using `SecureRandom`;
  constructor accepts a `Random` for tests; default constructor uses `SecureRandom`. Document the
  collision math in Javadoc (62^7 about 3.5 trillion; about 0.14 collisions per million inserts).
- `UrlValidator.validate(String raw)` returns the canonical URL string or throws
  `UrlValidationException`. Rules: parse with `java.net.URI`; absolute; scheme `http` or `https`
  (case-insensitive, normalised to lower case); non-empty host, normalised to lower case; no user
  info; length at most 2048 after normalisation; reject literal hosts that are loopback, RFC 1918,
  link-local, `0.0.0.0/8`, multicast, `::1`, `fc00::/7`, `fe80::/10`, `169.254.169.254`, and the
  names `localhost` and `metadata.google.internal`; no DNS resolution ever. Use
  `InetAddress.getByAddress`-style literal parsing so no lookup happens; a helper that detects
  whether a host string is an IP literal is fine.
- `ReservedWords.isReserved(String)` for: `api`, `actuator`, `health`, `metrics`, `prometheus`,
  `swagger-ui`, `v3`, `api-docs`, `error`, `favicon.ico`, `robots.txt`, `.well-known`, `static`,
  `assets`, `stats`, `admin`, `login`, `h2-console`. Case-insensitive.
- `LogSanitizer.sanitize(String)` removes CR, LF and other control characters, truncates to 200
  characters, returns `"null"` for null. Static utility, private constructor.

## Task T-004: create link

Files: `service/LinkAllocator.java`, `service/LinkService.java`, `domain/AliasTakenException.java`,
`domain/CodeGenerationExhaustedException.java`, `domain/LinkNotFoundException.java`,
`api/dto/CreateLinkRequest.java`, `api/dto/LinkResponse.java`, `api/LinkController.java`,
`api/ApiExceptionHandler.java`, `api/ShortUrlBuilder.java`, `config/ClockConfig.java`
(a `Clock` bean, `Clock.systemUTC()`), tests `LinkAllocatorTest` (real H2, full
`@SpringBootTest` or `@DataJpaTest` with `@Transactional(propagation = NOT_SUPPORTED)` so each
attempt commits), `LinkServiceTest` (Mockito), `LinkControllerTest` (`@WebMvcTest(LinkController)`
with `@Import(SecurityConfig.class)` and `@MockitoBean` services; use the header
`X-API-Key: test-api-key`), `ApiExceptionHandlerTest`, `LinkFlowIT`.

- `LinkAllocator.insert(code, url, now)` is `@Transactional` and saves a `Link`; the
  `DataIntegrityViolationException` escapes the proxy to the caller.
- `LinkService.create(CreateLinkRequest)` is not transactional. Validate the URL. If
  `customAlias` is present: check regex `^[A-Za-z0-9_-]{4,32}$` (already enforced by the DTO) and
  `ReservedWords` (400 via `UrlValidationException` field `customAlias`), then `existsByCode`
  fast-path 409, then one `insert`; a `DataIntegrityViolationException` whose message contains
  `uk_links_code` (case-insensitive) maps to `AliasTakenException`. Otherwise loop up to 5 times:
  `generator.next()`, `insert`; on the constraint violation retry; after 5 failures throw
  `CodeGenerationExhaustedException`. Increment counter `shortener.links.created` on success.
- `LinkService.get(code)` throws `LinkNotFoundException`. `LinkService.delete(code)` is
  `@Transactional`, throws `LinkNotFoundException` when nothing was deleted.
- `CreateLinkRequest(@NotBlank @Size(max = 2048) String url, @Pattern(regexp =
  "^[A-Za-z0-9_-]{4,32}$") String customAlias)`; `customAlias` optional.
- `LinkResponse(code, shortUrl, url, createdAt)`. `ShortUrlBuilder.shortUrl(code)` uses
  `AppProperties.baseUrl()` when set, else `ServletUriComponentsBuilder.fromCurrentContextPath()`.
- `LinkController`: `POST /api/v1/links` consumes `application/json`, returns 201 with
  `Location: /api/v1/links/{code}` and the body; `GET /api/v1/links/{code}` 200;
  `DELETE /api/v1/links/{code}` 204. Path variable constrained by the regex
  `{code:[A-Za-z0-9_-]{4,32}}`.
- `ApiExceptionHandler extends ResponseEntityExceptionHandler`, `@RestControllerAdvice`. Map:
  validation (`MethodArgumentNotValidException`, `UrlValidationException`) to 400
  `ProblemTypes.VALIDATION_FAILED` with `errors: [{field, message}]`;
  `HttpMediaTypeNotSupportedException` 415; `HttpRequestMethodNotSupportedException` 405;
  `HttpMessageNotReadableException` 400 validation-failed with a safe detail (never the parser
  message); `NoResourceFoundException` and `NoHandlerFoundException` 404 `LINK_NOT_FOUND` with
  detail "No resource at this path"; `LinkNotFoundException` 404; `AliasTakenException` 409;
  `CodeGenerationExhaustedException` 500 `CODE_GENERATION_EXHAUSTED`;
  `DataAccessResourceFailureException` and `CannotGetJdbcConnectionException` 503
  `SERVICE_UNAVAILABLE` with header `Retry-After: 5`; any other `Exception` 500 `about:blank`
  with detail "Unexpected error" and a server-side log line that includes the request id. Every
  body is built with `ProblemDetails.of(...)` so `requestId` and `timestamp` are present; override
  `createProblemDetail` or `handleExceptionInternal` so framework-produced bodies get the same two
  fields. Responses use content type `application/problem+json`.
- `LinkFlowIT` (`RANDOM_PORT`, `RestTestClient`): create returns 201 with `Location` and a
  7-character code; custom alias is honoured; reserved alias 400; duplicate alias 409 with
  `type` `/problems/alias-taken`; invalid URL 400 with `errors[0].field == "url"`; missing key 401;
  wrong content type 415; GET returns the link; DELETE returns 204 then GET returns 404.

## Task T-005: redirect and click recording

Files: `api/RedirectController.java`, `domain/ClickRecorded.java` (record `linkId`,
`occurredAt`, `requestId`), `service/ClickRecorder.java`, `config/ClickRecorderExecutorConfig.java`,
tests `RedirectControllerTest` (`@WebMvcTest` with `@Import(SecurityConfig.class)`),
`ClickRecorderTest` (unit), `ClickRecorderExecutorConfigTest` (rejection increments the counter
and does not block), `RedirectIT`, `ClickRecordingIT`.

- `RedirectController`: `GET /{code:[A-Za-z0-9_-]{4,32}}` resolves via `LinkService.resolve(code)`
  (one `findByCode`), publishes `ClickRecorded(link.id, clock.instant(),
  MDC.get(ProblemDetails.REQUEST_ID))` through `ApplicationEventPublisher`, returns 302 with
  `Location` set to the stored URL and `Cache-Control: no-store` set explicitly. `HEAD` on the same
  path resolves but publishes nothing. Unknown code: `LinkNotFoundException` (404). Increment
  `shortener.redirects` tagged `outcome=hit` or `outcome=miss`. Nothing from the request is read
  after the event is published.
- `ClickRecorder`: `@Component`, `@Async("clickRecorderExecutor") @EventListener` on
  `ClickRecorded`, saves a `ClickEvent`; catches every exception, logs once with the request id,
  increments `shortener.clicks.dropped` tagged `reason=error`; never rethrows.
- `ClickRecorderExecutorConfig`: `@Configuration @EnableAsync`; bean `clickRecorderExecutor`
  (`ThreadPoolTaskExecutor`, `defaultCandidate = false` on `@Bean`, core 2, max 4, queue 1000,
  thread name prefix `click-recorder-`, `waitForTasksToCompleteOnShutdown = true`,
  `awaitTerminationSeconds = 10`, rejection handler increments `shortener.clicks.dropped` tagged
  `reason=saturated` and drops). Constants, not properties.
- `ClickRecordingIT`: a redirect records exactly one click (Awaitility, at most 5 seconds); a
  `HEAD` records none; with `@MockitoBean ClickEventRepository` throwing on save, the redirect is
  still 302 and `shortener.clicks.dropped` increments.
- `RedirectIT`: 302 with `Location` and `no-store`; unknown 404 Problem; malformed code such as
  `/favicon.ico` never reaches the repository (verify with a `@MockitoSpyBean` or by asserting 404
  with a code that fails the regex).

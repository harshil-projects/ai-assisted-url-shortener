# Prompt v1: attribution slice (task T-202 and the test part of T-203)

Executed as one generation session on a worktree of `main` after the greenfield commits, in
parallel with the brownfield batch; the engineer merges both and resolves overlaps.

## Role and ground rules

You are implementing the decision recorded in `harness/requirements/R-03.md` (section "Decision")
and specified in `harness/tasks/T-202.yaml`. Read both in full first, then `T-203.yaml`,
`docs/decisions/0006-no-ip-or-user-agent-persisted.md`, `AGENTS.md`, and the code you will change:
`domain/ClickEvent`, `domain/ClickRecorded`, `service/ClickRecorder`, `api/RedirectController`,
`repository/ClickEventRepository`, `service/AnalyticsService`, `api/dto/StatsResponse`, the V1
migration and the tests that cover them.

Hard constraints:

- Privacy first: no IP address, no user agent, no full referrer URL, no geography, no device value is
  read, derived, logged or stored. The only inputs are the `Referer` header's host and the three
  `utm_*` query parameters of the short link request. A test asserts that `click_events` has exactly
  the seven columns after V3.
- Everything attribution-related is computed on the request thread into the immutable
  `ClickRecorded`; the recorder reads nothing from the request.
- Redirect semantics do not change: 302 to the stored URL, query parameters are recorded, not
  forwarded; `Cache-Control: no-store` stays.
- Boot 4 idioms, constructor injection, records, methods under 50 lines, files under 400 lines,
  `spotless:apply` before every verify. No new dependencies; no edits to `pom.xml`,
  `application*.properties`, security or filter classes, `ProblemWriter`, `ProblemDetails`.
- Never weaken an existing test. Do not run git. Files only under `url-shortener/src`,
  `docs/reference/`, and `CHANGELOG.md`.
- Finish with `./mvnw.cmd -B -ntp verify` green; regenerate the OpenAPI export when a record or
  controller changes (`./mvnw.cmd -B -ntp -pl url-shortener -Dtest=OpenApiIT
  -Dsurefire.failIfNoSpecifiedTests=false -Dopenapi.update=true -Djacoco.skip=true test`).

## Task T-202

- `V3__add_click_attribution.sql`: four statements, one `ALTER TABLE click_events ADD COLUMN` each:
  `referrer_host VARCHAR(253)`, `utm_source VARCHAR(64)`, `utm_medium VARCHAR(64)`,
  `utm_campaign VARCHAR(64)`, all nullable; comment states the task and the privacy position.
- `domain/ClickAttribution` (record `referrerHost`, `utmSource`, `utmMedium`, `utmCampaign`, all
  nullable) with `static ClickAttribution from(String refererHeader, Map<String, String[]> query)`:
  parse the referer with `java.net.URI`, keep only the lower-cased host when the URI is absolute
  with a host, truncate to 253; for each utm key take the first value, remove ISO control
  characters, trim, truncate to 64, empty becomes null. Never throws. Unit-test every rule
  (`ClickAttributionTest`, parameterised).
- `ClickRecorded` carries the attribution; `ClickEvent` gains the four nullable columns;
  `ClickRecorder` copies them. `RedirectController.redirect` builds the attribution from
  `request.getHeader("Referer")` and `request.getParameterMap()` before publishing; `HEAD` still
  publishes nothing.
- `ClickEventRepository`: `topReferrers(long linkId, int limit)` and `topCampaigns(long linkId,
  int limit)` as JPQL group-by queries ordered by count descending then name, excluding null hosts
  (campaigns: exclude rows where all three fields are null), returning record projections
  `api/dto/ReferrerStats(String host, long clicks)` and `api/dto/CampaignStats(String source, String
  medium, String campaign, long clicks)`. Use `Pageable`/`Limit` for the top ten.
- `StatsResponse` gains `referrers` and `campaigns` (lists, at most ten, never null; empty lists
  when nothing was recorded). `AnalyticsService` fills them inside the existing read-only
  transaction.
- Tests: `MigrationTest.v3AddsNullableAttributionColumns` (and the seven-column assertion);
  `ClickEventRepositoryTest.topReferrersAndCampaigns` (ordering, limit, null exclusion);
  `AttributionIT` over HTTP: redirect with `Referer: https://News.Example.com/story?x=1` and
  `?utm_source=newsletter&utm_medium=email&utm_campaign=oct` → stats show `news.example.com` and
  the triple; redirect without `Referer` records a null host and still counts; a `Referer` that is
  not a URL records null; `utm_*` values with control characters are cleaned and long values
  truncated; query parameters are not forwarded (`Location` equals the stored URL exactly);
  `StatsIT` and `RedirectIT` keep passing.

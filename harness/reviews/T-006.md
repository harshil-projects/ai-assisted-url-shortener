## Data-deletion assessment

| Question | Answer |
|---|---|
| What is deleted | One `links` row and, through the database cascade, its `click_events` rows |
| Is it reversible | No; hard delete, as the design chose for the prototype |
| Who can trigger it | Any holder of the single API key; there is no per-user audit (documented limitation) |
| Is the alias reclaimable afterwards | Yes; a deleted alias can be re-created by someone else. Recorded in `docs/risks-and-limitations.md` as alias reclaim |
| Is deletion logged | The request id and code appear in the access path logs; no dedicated audit record |
